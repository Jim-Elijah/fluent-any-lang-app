## 📱 跨端原生应用：`fluent-any-lang-app`

为了给语言学习者带来更完整、无缝的精听体验，我们正式推出了官方跨端原生客户端：**FluentAnyLang App**！

* 🌐 **官方主页**: [FluentAnyLang App Website](https://app.fal.jimelijah.com/)
* 📲 **支持平台**: iOS、Android、macOS、Windows、Linux

### 为什么需要 Flutter 原生客户端？
Web 版本提供了零门槛即开即用的便捷体验，而基于 Flutter 重构的原生客户端则彻底突破浏览器沙箱限制，满足严肃精听学习者的核心诉求：
* 🎧 **后台锁屏播放与线控交互**：通勤、跑步锁屏状态下持续精听，支持耳机实体按键切换句子与重听。
* 🎙️ **原生低延迟双轨录音对比**：毫秒级精准音频捕获，实时呈现“原声波形 vs 个人发音波形”对比。
* 📁 **直接访问本地大容量媒体库**：不再受限于浏览器存储额度，直接管理与秒级打开 GB 级影音素材库。
* ☁️ **BYOS 多端数据同步**：支持自主存储（WebDAV / iCloud / Google Drive），手机、平板、电脑间跟读进度与标注无缝漫游。

👉 **欢迎访问 [FluentAnyLang App 官方网站](https://app.fal.jimelijah.com/)** 查看新版特性演示与报名内测体验！

## ✨ 核心特性

- 🎧 **句级精准循环**：点击字幕任意单句即刻定点循环，支持微调慢速播放与音素拆解。
- 📊 **双轨波形音准对比**：直观对比语调起伏、节奏断句与音素强弱，告别“盲目跟读”。
- 🔒 **Local-first 极致隐私**：音频、视频、录音和跟读历史均保存在本地设备，不上传云端。
- 📑 **主流格式全兼容**：顺畅导入 MP3、WAV、MP4、MKV 等音视频，支持 SRT、VTT、LRC 字幕。
- 🌍 **全界面多语言支持**：原生支持中英等多种语言界面切换。
